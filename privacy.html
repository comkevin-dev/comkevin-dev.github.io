오스뮤 스튜디오 개인정보처리방침

시행일: 2026년 11월 15일 · 운영자: Comkevin · 문의: dailywelllife.official@gmail.com · 홈

1. 앱 소개

오스뮤 스튜디오(OSMU Studio)는 운영자가 자신의 유튜브 채널 「건강 반상회 | Daily Well Life」를 관리하기 위해 운영자 본인의 컴퓨터에서만 실행하는 개인용 프로그램입니다. 일반 사용자에게 배포하거나 판매하지 않습니다.

2. 이용하는 Google 사용자 데이터와 목적

오스뮤 스튜디오는 YouTube API 서비스(YouTube Data API v3, YouTube Analytics API)를 사용하며, 운영자가 Google 계정으로 직접 허용한 경우에만 다음 데이터에 접근합니다.

  • 운영자 채널의 영상 정보(제목, 설명, 자막 목록): 자막 파일과 영어·일본어 제목·설명을 올리기 위해
  • 운영자 채널의 재생목록: 영상을 재생목록에 넣고 재생목록 설명을 고치기 위해
  • 운영자 채널 영상의 통계(조회수, 좋아요, 댓글 수, 공유, 구독자 증가): 게시물 성과를 기록하기 위해

오스뮤 스튜디오는 영상을 업로드·삭제하거나, 공개 범위를 바꾸거나, 댓글을 쓰지 않습니다. 다른 사람의 채널이나 시청자의 개인정보에는 접근하지 않습니다.

3. 저장

Google 인증 정보(토큰)와 위 데이터는 운영자 본인 컴퓨터에만 저장되며, 별도의 서버나 클라우드에 저장하지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 누구에게도 판매·공유·전송하지 않으며, 광고나 다른 목적으로 사용하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

오스뮤 스튜디오가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 보관 기간과 삭제

  • 앱의 [연결 끊기]를 누르면 저장된 인증 정보가 삭제되고 Google 권한도 취소됩니다.
  • Google 계정 설정에서 언제든 권한을 취소할 수 있습니다: https://security.google.com/settings/security/permissions
  • 통계 기록은 운영자가 필요 없을 때 직접 삭제합니다.

7. 관련 약관

  • YouTube 서비스 약관
  • Google 개인정보처리방침

OSMU Studio Privacy Policy

Effective: November 15, 2026 · Operator: Comkevin · Contact: dailywelllife.official@gmail.com

OSMU Studio is a personal tool that runs only on the operator's own computer to manage the operator's YouTube channel "건강 반상회 | Daily Well Life". It is not distributed to the public.

It uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API) only with the operator's explicit consent, to: upload caption files and English/Japanese titles and descriptions to the operator's videos; add videos to the operator's playlists and edit playlist descriptions; and read view, like, comment, share and subscriber statistics for the operator's videos. It does not upload or delete videos, change privacy settings, or post comments, and it does not access other channels or viewers' personal data.

Tokens and data are stored only on the operator's computer and are never sold, shared or transferred to third parties, or used for advertising.

OSMU Studio's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time with the app's [Disconnect] button or at https://security.google.com/settings/security/permissions.
